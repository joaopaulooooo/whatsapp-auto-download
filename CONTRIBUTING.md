# Contribuindo

Obrigado por interessar-se em contribuir com o WhatsApp Auto-Download Bot!

## 🤝 Como Contribuir

### Reportando Bugs

Antes de criar uma issue, verifique se o bug já foi reportado.

Ao criar uma issue de bug, inclua:
- Descrição detalhada do problema
- Passos para reproduzir
- Comportamento esperado vs. comportamento atual
- Ambiente (SO, versão do Node.js, etc.)
- Logs relevantes

### Sugerindo Novas Funcionalidades

- Verifique se a funcionalidade já foi solicitada
- Descreva claramente a funcionalidade proposta
- Explique o caso de uso
- Considere abrir uma discussão primeiro

### Pull Requests

1. **Fork** o repositório
2. Crie uma **branch** para sua feature
   ```bash
   git checkout -b feature/minha-feature
   ```
3. **Commit** suas mudanças
   ```bash
   git commit -m 'Adiciona minha feature'
   ```
4. **Push** para a branch
   ```bash
   git push origin feature/minha-feature
   ```
5. Abra um **Pull Request**

## 📋 Padrões de Código

- Use JavaScript moderno (ES6+)
- Siga o estilo de código existente
- Comente código complexo
- Mantenha funções pequenas e focadas
- Use nomes descritivos para variáveis e funções

## 🧪 Testes

- Teste suas mudanças antes de abrir um PR
- Verifique que o bot inicia sem erros
- Teste o download de diferentes tipos de arquivos

## 📝 Commits

Use mensagens de commit claras e descritivas:

- ✅ `feat: add suporte para novos formatos`
- ✅ `fix: corrigir bug na limpeza de arquivos`
- ✅ `docs: atualizar README`
- ❌ `update stuff`
- ❌ `fix bug`

## 🌐 Idioma

Este projeto é internacional. Fique à vontade para:
- Reportar bugs em inglês ou português
- Escrever código em inglês (variáveis, funções, comentários)
- Traduzir documentação

## 📧 Contato

Para dúvidas, abra uma issue ou discussion.

---

Lembre-se: contribuições de qualquer tamanho são bem-vindas!
